🌦 Weather Live Telegram Bot

 About Project
This Telegram bot provides real-time weather information for any city.

After entering a city name, users can receive:
- Current temperature
- Current local time in the city
- Weather condition
- Sunrise and sunset times
- Wind speed
---

 Multilingual Support
The bot can respond in:
- 🇺🇿 Uzbek
- 🇷🇺 Russian
- 🇬🇧 English

---

 Technologies
- Python
- Telegram Bot API
- Weather API

---

 Features
- Real-time weather updates
- City search
- Multilanguage support
- User-friendly interaction

---

 Purpose
Created for learning API integration, multilingual systems, and backend development.

---

## ⚠️ Note
This bot currently runs locally and is not hosted on a server.
